# Infosys Financial Analysis Dashboard | Power BI

## Project Overview

Developed an interactive Power BI dashboard to analyse the financial performance and financial position of Infosys Ltd. over FY2016–FY2025.

The project combines financial statement analysis with data visualization to identify key trends in revenue, profitability, earnings, capital structure and financial leverage.

## Objectives

- Analyse revenue and profitability trends
- Evaluate operating profit and net profit performance
- Analyse EPS and profitability ratios
- Examine capital structure and borrowings
- Evaluate debt-to-equity position
- Present financial insights through an interactive dashboard

## Tools & Skills

- Power BI
- DAX
- Power Query
- Microsoft Excel
- Financial Statement Analysis
- Data Visualization

## Key Financial Insights

- **Strong growth:** Revenue increased from ₹68,484 crore in FY2016 to ₹1,78,650 crore in FY2025, a ~161% increase.
- **Profit growth:** Operating profit and net profit increased by ~127% and ~105%, respectively.
- **Improved shareholder earnings:** EPS increased from ₹31 to ₹73, indicating substantial growth in earnings per share.
- **Strong return on equity:** ROE increased from approximately 20.8% to 31.7%, indicating improved returns generated on shareholders' equity.
- **Margin pressure:** Operating profit margin and net profit margin declined over the period, suggesting some pressure on profitability efficiency despite strong absolute profit growth.
- **Low financial leverage:** FY2025 debt-to-equity stood at around 0.10, indicating relatively low dependence on borrowings.

## Overall Assessment

Infosys demonstrated strong long-term growth with significant improvement in revenue, profits and EPS while maintaining relatively low financial leverage. However, declining profit margins indicate the need to monitor profitability efficiency as the business continues to expand.

## Data Source

## Project Scope
